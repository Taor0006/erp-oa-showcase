# 技术与运行环境

本页介绍同一套 ERP/OA 系统的技术基础和已记录演示环境，供了解部署形态与模块协作方式。

## 技术结构

| 部分 | 技术及作用 |
| --- | --- |
| 业务前端 | Vue 3、Frappe UI、ECharts，提供考勤、审批、采购和研发工作台 |
| 应用后端 | Python、Frappe、ERPNext、HRMS，以及按企业需求定制的业务模型 |
| 持久化 | MariaDB |
| 队列及后台任务 | Redis、Frappe 后台任务 |
| 构建与环境 | Vite、Yarn、Docker 与 Compose |
| 可选发票能力 | 独立 PaddleOCR 服务，默认演示环境不包含该服务 |
| 检查 | Python / Node 测试、生产构建、HTTP 权限与业务检查 |

## 部署形态

本地全栈演示采用 Docker Linux 容器与 Compose v2，包含应用、站点、数据库、队列与网页入口。基础镜像使用 Frappe 官方 ERPNext 15 系列镜像，按固定依赖构建。

演示准备条件包括 Git、Python 3.10+ 和 Docker。已有文档建议为本地演示构建预留 4 核、8 GB 内存及至少 20 GB 可用磁盘；这是演示构建建议，未经过生产负载验证。

演示站点只提供本机访问，使用独立容器网络和持久卷；数据库与 Redis 不开放宿主机端口。账号密码、数据库、附件与运行日志由环境单独管理。已有记录验证了停止服务后保留数据，以及恢复启动后的访问检查。

公网部署需要另行完成域名、HTTPS、访问策略、备份和运行监控配置。本展示仓库仅提供环境与架构说明，业务源码和部署实现保留在私有仓库。
